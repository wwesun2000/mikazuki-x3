# Windows 游戏界面重建要求

PC 玩家界面接收 C++ 游戏核心确认的画面、文字与可用动作。玩家窗口从原文件创建会话。独立的 Win32 选择窗口从原版晚餐存档核对分支与键鼠。系统字体可用于中英日显示，原文字时序、排版指令和选择条件由游戏核心执行。下列行为须在相应范围逐项验收。[当前原盘路线](../DECOMPILATION_ROUTE.md) · [可机读契约](game-ui-contract.json)

| 玩家操作 | 新界面的行为 |
|---|---|
| 进入剧情 | 原场景靠顶，桌面空间允许时从顶边到底边填满可用高度，完整保留显示比例与构图。左侧仅放游戏操作。当窗口过窄时收起侧栏、等比缩放，原画保持完整。 |
| 看台词和提示 | 文字按场景直接叠在原画上，以细描边保持可读，无对话框、底板或常驻页码。原图和原声按原调度呈现。个别图片含必要提示时，在其对应对话中以本地化提示说明，只显示当时可知的信息。 |
| 选择分支 | 键盘方向与确认、取消、回看沿用原手柄在该上下文的含义。鼠标可直接点整项。鼠标与键盘公用有效项、一次确认和原过渡，核心计算目标。普通文字选项和人物卡分别验收。 |
| 打开系统菜单 | 左侧按原版提供时间图、结局列表、环境设置、游戏结束（保存）。各项只在原状态允许时可用，展示已解锁信息。关闭时恢复调用位置和焦点，当次按键不会同时推进剧情。 |
| 自动推进 | 在原输入允许时按 T 或点左栏打开五档间隔，左右调整，回车确认、退格取消。运行中按 I 或点「停止自动推进」走原停止流程，保留当前对白与存档位置。 |
| 查看操作说明 | 按住 Page Down 显示原 ELF 中的按键说明，松开返回。说明与当前语言同步，保留当时的剧情、音频和文字揭示位置。 |
| 查看背景 | 按住 End（原 R2）隐藏文字，左右键打开并调整亮度，松开回到原对白。鼠标可点「查看背景」再调亮或调暗，点「返回剧情」松开 R2。可用性取决于原剧情输入状态。 |
| 保存和继续 | 从原允许的位置保存。跨进程加载后在同一分支、等待或待决选择恢复，同时核对已读、场景、原声位置。写盘失败保留可用进度并报告失败。 |
| 新游戏建卡 | 选篇后可直接开始，或选择一个原记忆卡记录建立进度。已有记录须确认覆盖，取消则保留原进度。标题的「继续进度」按篇列出可读取的记录。 |
| 随时换语言 | 选定中英时，第一帧起只呈现已解锁的对应译文。逐字中、等待、选项、菜单和读档后切换均保留进度、选项焦点与原声位置。中文须全量初译后整体校对再发布。 |
| 调整画面 | 使用 Windows 通用图形接口和常规驱动。验收原比例全屏与窗口切换、常规重采样、可选扫描线和稳定重绘。文字和菜单在滤镜后合成。 |

视觉沿用已认可的细线图标、窄深色侧栏、低干扰的对白叠字。图标尺寸、描边与侧栏宽度需要在实际 DPI 和窗口尺寸上验证。[视觉参考](../../design/ui/concept-v2.png) · [原版菜单与操作证据](../UI_GAMEPLAY_SOURCES.md)

记录构建、原脚本位置、测试起点、实际输入、设备、语言、预期与实测。以截图和动作/状态日志为主，只为单帧截图无法表达的闪字、输入时序或音画同步问题录短片。Android 在 PC 完成后以同一动作与分支语义适配触控、系统返回、安全区、后台和音频中断。

Windows 侧栏的操作文字在 700 像素高的客户区以 22 像素绘制，随窗口高度调整。玩家反馈问题时可直接截全窗。侧栏最下方的小号浅灰码标出原脚本位置；窄屏收起侧栏时，有下方留白才在留白中显示。标题菜单也有对应位置码。

画面和语言设置融入游戏窗口内的设置页，复用主菜单的字体、颜色、焦点条和返回方式，不使用独立 Windows 弹出菜单。标题页提供「设置」，剧情侧栏与 F1 进入同一页；关闭后恢复原页面及其焦点。方向键选择/调整，○确认、×或 Esc 返回，鼠标整行点选。退出设置所用按键须等抬起后才重新交给原游戏，不能同时推进台词或确认分支。窄窗口也须能操作全部设置。

「关于与贡献」是设置页内的子页面，展示技术交流、禁止商用、需要自备原盘 ISO 的说明，以及 wwesun2000、OpenAI Codex、Claude、Gemini 的实际贡献。小窗口可用方向键、Page Up/Down、Home/End 或滚轮浏览全部内容；确认/返回回到设置的原入口焦点，不推进游戏。原作权利与移植协作贡献分开标注。

按 F12 或点「设置」中的「保存截图」，把当前客户区保存为 PNG。截图保留当时的语言和滤镜，文件名含对应位置码，正文不会因截图操作推进。播放器在运行目录的 `captures/screenshots/` 保留有视觉差异的画面，相同位置与显示设置下的相同截图复用一个文件。

原保存目标允许十个槽位。PC 侧栏每次显示五个，鼠标可切换槽位组，键盘上下可遍历全部十个。标题的「继续进度」分别标示 PC 存档和原记忆卡存档。槽位沿用各篇原有的编号和文件路径。

从「结束并保存」按 Tab 或点击「原版记忆卡」进入原存档程序。第一问取消返回游戏菜单；空卡可选接口和记录，有绑定记录时写回原目标。不保存退出须在原确认页明确选择「是」才返回标题。确认图保留原盘日文，在图下显示当前语言的提示。鼠标和键盘均经原卡页的焦点及确认函数处理。

开发者从项目根目录运行 `./tools/python.ps1 tools/decode_screen_location.py <定位码>`。开头的版本号为 1，随后是作品编号。其余分段使用 36 进制，分别还原脚本选择器、原标签编号、相对脚本起点的字节位置。原系统菜单打开时另有页面、焦点和子焦点。标题菜单使用独立前缀 `10`。位置码只读取当时的状态，适合找到对应指令；重现由历史选择引起的问题仍需存档或操作步骤。

同一个命令也接受 F12 生成的原文件名或完整 PNG 路径，可一并还原截图时的语言、缩放和扫描线设置。游标常停在等待指令之后，输出会给出邻接的上一条指令及同一段前方的文字记录 ID，方便用原文核对。截图改名后，可以手动输入画面上的定位码。
