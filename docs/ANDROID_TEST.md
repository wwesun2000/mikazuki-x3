# Android 测试版 0.1.1

这是现有 Windows 原生移植的 Android 前端，共用 `port/core/` 的原游戏逻辑、原盘资源验证、翻译和存档格式。没有另建剧情播放器，也不运行 PS2 模拟器。此阶段先提供可安装的测试包。

## 安装与开始

1. 将 `MikazukiX3-Android-0.1.1-test-arm64-v8a.apk` 复制到手机安装。此包使用测试证书，暂未上架应用商店。已有 0.1.0 可直接覆盖安装并保留应用内进度，不要先卸载。
2. 将自己持有的日版原盘 ISO 放到手机本地存储。支持的镜像为 SLPM-66452，大小 **3,594,551,296 字节**。保持 ISO 格式，不要解包，也不要选择 ZIP/7z 压缩包。
3. 打开应用，点「选择游戏 ISO」。在 Android 系统文件选择器中找到该文件。系统会授予这个文件的读取权限；应用直接随机读取原盘，不额外复制整盘素材。
4. 点「从头开始」，选择篇章。默认显示简体中文，保留原图和原声。右侧「设置」可切换日中英文字和扫描线滤镜。画面使用普通平滑缩放，不含 AI 超分或其他滤镜选择。

应用不需要 BIOS、不需要联网，也不申请整个存储空间的访问权限。如果移动或删除了 ISO，请重新选择。云端文件提供程序若只提供不可定位的流，需先将 ISO 下载到手机本地。

## 触屏操作与进度

- 横屏显示，完整 4:3 场景居中，两侧放操作菜单；对白直接显示在场景上，没有对话底板。
- 安卓使用纯触屏：轻点场景推进对白，分支直接点整项；不显示方向键或模拟手柄按钮。向下滑动回看，向上滑动执行原向前动作；列表上下滑动，姓名字符组左右滑动。内部仍传入原游戏动作，不改写剧情变量。
- 两侧菜单采用新绘制的月夜孤岛背景、细线图标和金色选中标记。该美术仅用于应用界面，游戏里的原图片保持原样。
- 左侧「游戏菜单」进入原版章节、结局、时间图、游戏设置和结束/保存等操作；可用项目由原游戏状态决定。
- 从原菜单的「结束并保存」进入十个存档槽位。已占用槽位会询问是否覆盖；保存完成回标题后，从「继续进度」读取。
- 章末存卡和「原记忆卡」入口保留原保存流程。实际写入后，可在对应篇章的继续页面选择「原记忆卡记录」读取。触屏确认经原方向键移焦和原确认函数执行。
- 应用切后台时暂停原逻辑和音频输出，并另存上次会话快照；重启后，在相应篇章的继续页面选择「继续上次离开的位置」。它不替代重要节点的手动存档。
- 设置页切换语言和滤镜不推进剧情。原声与图像不翻译；解释性提示只随原有已揭示文字出现。
- 「查看背景」与「返回剧情」切换原背景查看状态；在原逻辑允许时，可点「场景亮度」后用「更暗／更亮」调整。姓名/答题输入使用原字符表，可直接选字、滑动或点「上一组／下一组」、删除、完成，并经过原确认过程。
- 「自动推进」打开原间隔设置，直接点 1–5 的等级再点「开始自动推进」；「返回」取消。连续快速点击也会等待原焦点到达目标等级再确认。

存档在应用私有目录中。**卸载应用或清除应用数据会删除手机存档**。当前测试版未提供面向用户的 PC 存档导入/导出按钮；Android 与 PC 共用序列化格式，专项测试也使用了已知 PC 样本。

## 截图反馈

点右侧「截图」会保存完整画面，左下角的小号定位码也会保留。Android 10+ 保存到相册 `Pictures/MikazukiX3`；Android 8/9 使用系统保存文件窗口。文件名包含脚本位置、语言、平滑缩放和扫描线状态。

反馈问题时，请保留原 PNG 文件名，并附手机型号、Android 版本、出现问题前的操作。定位码能指向原脚本等待位置，但不能单独还原此前全部分支选择。

## 兼容性范围

- 首批手机目标：**64 位 ARM、Android 8.0/API26 及以上**；用户首测设备为 iQOO Z9 Turbo。
- 使用 Android Canvas、标准文件访问接口、AAudio 和应用内 FFmpeg 解码，不依赖特定 GPU 品牌扩展。
- APK 内所有本机共享库已检查 16KB LOAD 段对齐、依赖、签名及 ZIP 对齐。该检查不代表已通过所有 16KB 页设备的实际运行验证。
- 已分别检查 Android 11 的 x86_64 执行与该模拟器 ARM 翻译环境中的 ARM64 安装包。**iQOO 真机、其他 Android 版本、刘海/挖孔尺寸、蓝牙音频以及长时间运行仍需实机反馈。**
- 这是首个触屏测试版；尚未实现逐控件 TalkBack、独立大字号模式、原生 32 位 ARM 包和面向用户的存档迁移入口。没有声称全部分支已在 Android 重走验证。

## 开发与复现

工具链都位于本项目 `local/dependencies/android`；无需全局安装 Android Studio 或修改全局 Java 环境。

```powershell
./tools/python.ps1 tools/android_bootstrap.py
./tools/python.ps1 tools/android_media_setup.py
./tools/python.ps1 tools/build_android.py --abi arm64-v8a
./tools/python.ps1 tools/package_android.py --abi arm64-v8a
```

构建复用 `local/pc-core/player/*locale_data.inc` 的已采用译文。APK、SHA-256 和原生输入指纹写入 `local/releases/android`。测试证书留在 `local/android-build/test-signing.keystore`，不要提交到公开仓库；后续覆盖安装测试版需要继续使用同一证书。

平台实现位于 `port/platform/android`。当前复用的若干可移植类仍在 `port/platform/windows` 路径下：游戏会话、存档、资源调度、原音频混音、字体和电影元数据。Android 替换实际文件传输、FFmpeg 内存解码、AAudio 输出及窗口/触控，保留原逻辑。

SAF 的文件描述符不能依赖 `/proc/self/fd` 再打开；Android 通过 `RetailDisc::ReadAt` 的 `pread` 接口读取。原 Windows 路径构造继续使用 `ifstream`。两种读取方式已用实际 ELF、字体、50MB 音效及特效逐字节/哈希比较，并覆盖超过 2GiB 的偏移与短读重试。

交互契约：`docs/ui/android-game-ui-contract.json`。测试证据和明确的起点/边界：`analysis/android/`。16KB/依赖等独立检查：`analysis/android/sol/apk-compatibility.json`。
