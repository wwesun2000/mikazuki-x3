使用说明与贡献
本程序仅供技术交流，禁止商用。请自行准备游戏原盘镜像（ISO）进行游戏。
本程序不附带游戏光盘素材。原作及其素材权利归相应权利人所有。

以上为本移植项目的协作贡献；程序内可在「设置 → 关于与贡献」查看。

启动
1. 将整个播放器文件夹放在可写的位置，保留其子目录结构。
2. 双击 Play-PC.cmd，选择自己的原版日本版 ISO。也可把 ISO 拖到 Play-PC.cmd 上。
3. 选择篇章和“新游戏”或“继续进度”。首次运行不需要 PS2 BIOS 或模拟器。

原图、原声和游戏数据直接从 ISO 读取。请保留 ISO；本包不附带光盘素材。
程序会记住已选的 ISO 位置。移动 ISO 后，再选择新的位置即可。
当前仍为试玩版本，不能据局部验证视为所有路线均已完整通关验收。

操作
鼠标可点选菜单及剧情选项。键盘动作仍由原游戏当前状态决定。
方向键：原手柄方向键。
Enter / Space / L：○。Backspace / K：×。I：△。J：□。
Page Up / Page Down：L1 / R1。Home / End：L2 / R2。T：START。
在允许的剧情状态，按住 Page Down 查看操作说明；按住 End 查看背景。

F1：游戏内设置（文字语言、画面滤镜、全屏、截图及关于与贡献）。
F2：切换普通平滑缩放。F3：扫描线。F4：Scale2x 滤镜。
F6：切换日文、中文、英文。切换不改变剧情、选项焦点或原声。
F11：切换全屏。全屏中按 Esc 返回窗口。
F12：保存当前窗口截图。相同画面的重复截图复用已有文件。

保存与反馈
从原游戏允许保存的位置使用游戏菜单保存或结束。PC 存档与原版记忆卡记录分别显示。
十个槽位均可使用；PC 槽位列表每次显示五个，可切换到后一组。
进度保存在 local/pc-core/player/saves/。备份或迁移时请复制整个 saves 文件夹，
包括其中的 memory-card 子目录；不要只复制单个会话文件。
截图保存在 captures/screenshots/。反馈问题时请保留完整截图及其原文件名，
并附对应存档与最近操作。左下角的小号位置码可帮助定位原脚本指令。

图像里的原有日文和原版配音保持不变；中英文替换的是游戏文字。
程序使用 Windows 通用图形接口与常规滤镜。当前测试机器为 AMD Radeon Graphics；
其他型号的具体驱动表现还需各自实测。
