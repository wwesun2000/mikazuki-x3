# Windows 原生移植 · 2026-11-03 当前记录

当前分发版本为 **567B9F85**，入口仍是项目根目录或 `local/windows-iso-player/Play-PC.cmd`。程序直接读取用户自己的原版 ISO；本包不附带光盘素材，也不需要 BIOS 或模拟器来运行正式播放器。当前是可试玩候选，不把局部通过视为全游戏发布验收。

已生成 [Windows 便携试玩包](../local/releases/KamaitachiX3-Windows-567B9F85-candidate.zip)，37,127,730 字节（约 35.4 MiB）。解压后保留目录结构，双击 `Play-PC.cmd` 选盘，或把 ISO 拖到该启动器。包内只有已验收的四个分发文件，没有 ISO、用户存档和配置；ZIP 内逐文件 SHA 与分发清单一致。

## 本阶段实际变化

- 画面与语言设置改为游戏窗口内的统一设置页，标题页、侧栏与 F1 共用。鼠标、方向键和原确认/返回键可操作；关闭使用的按键不会同时确认剧情选项。
- 同一设置页内加入「关于与贡献」，包含技术交流、禁止商用、自备原盘 ISO 的说明，以及 wwesun2000、OpenAI Codex（Astra/Sol）、Claude（Opus/Sonnet）、Gemini 的实际分工。中日英三语、小窗口滚动和返回焦点已验证。
- 对比此前 5E 冻结输入，本阶段正式构建仅改变窗口 UI 源码；剧情核心、重编译函数、资源与译文表未改。272 个当前/冻结输入和分发的四个文件均核对指纹。
